# 孕期胎儿记录功能说明

## 概述
孕期胎儿记录（Fetal Records）是应用中专门用于记录孕期胎儿超声检查数据和计算胎儿体重的功能模块。

## 功能特性

### 1. 超声测量数据记录
支持记录以下孕期超声检查数据：
- **孕周** *(必填)* - 当前孕周数
- **双顶径 (BPD)** - Biparietal Diameter，毫米
- **头围 (HC)** *(必填)* - Head Circumference，毫米  
- **腹围 (AC)** *(必填)* - Abdominal Circumference，毫米
- **股骨径 (FL)** *(必填)* - Femur Length，毫米
- **胎心率 (FHR)** - Fetal Heart Rate，正常范围 120-160 bpm
- **日期** - 检查日期
- **备注** - 医生建议或其他信息

### 2. 权威胎儿体重计算

本应用采用**国际权威的Hadlock公式**进行胎儿体重估算，该公式已被以下权威组织认可：
- ACOG（美国妇产科学会）
- WHO（世界卫生组织）
- FIGO（国际妇产科联盟）
- 国内三甲医院超声科标准

#### 使用的公式

**Hadlock III公式**（推荐，ACOG首选）
```
log₁₀(EFW) = 1.2622 + 0.0105(HC) + 0.0288(AC) - 0.0323(FL)

其中：
- EFW = 估计胎儿体重（克）
- HC = 头围（毫米）
- AC = 腹围（毫米）
- FL = 股骨径（毫米）
```

**Hadlock I公式**（4参数，准确性最高）
```
log₁₀(EFW) = 1.3596 - 0.0056(AC) + 0.0107(HC) + 0.0438(BPD) + 0.158(FL)

其中：
- EFW = 估计胎儿体重（克）
- BPD = 双顶径（毫米）
- HC = 头围（毫米）
- AC = 腹围（毫米）
- FL = 股骨径（毫米）
```

#### 精度范围
- **误差范围** ±10-15%（95% 置信度）
- **孕周范围** 14-42周
- **最佳准确性** 20-35周

### 3. 胎儿发育评估

计算结果包含百分位数评估，基于INTERGROWTH-21st国际标准：
- **P10** - 第10百分位（偏小）
- **P50** - 第50百分位（中位数/正常）
- **P90** - 第90百分位（偏大）

## 使用流程

### 1. 添加新记录
- 点击"我的"→"孕期胎儿记录"或直接在"我的"页面选择入口
- 点击"+ 新建记录"按钮
- 填写孕周和超声测量数据
- 可选填胎心率和备注

### 2. 计算胎儿体重
- 填写至少以下三个参数：头围(HC)、腹围(AC)、股骨径(FL)
- 点击"🧮 计算体重"按钮
- 系统自动计算体重并显示：
  - 估计体重（克）
  - 使用的公式版本
  - 百分位数评级
  - 与参考值的偏差

### 3. 保存记录
- 确认计算结果无误
- 点击"💾 保存记录"保存到数据库
- 可在列表中查看、编辑或删除

### 4. 查看详情
- 点击记录卡片上的"📊 查看详情"
- 查看完整的测量数据、计算结果和参考范围
- 显示重要医学提示

## API函数文档

### fetalCalculator.js

#### `calculateFetalWeight(params)`
**自动选择最优公式计算胎儿体重**

参数：
```javascript
{
  bpd: number,      // 双顶径 (毫米)，可选
  hc: number,       // 头围 (毫米)，必需
  ac: number,       // 腹围 (毫米)，必需
  fl: number        // 股骨径 (毫米)，必需
}
```

返回值：
```javascript
{
  weight: number,        // 胎儿体重（克）
  formula: string,       // 使用的公式名称
  accuracy: string,      // 精度范围
  error?: string         // 错误信息（如果有）
}
```

#### `classifyFetalWeight(weight, gestationalWeek)`
**评估胎儿体重百分位**

参数：
- `weight` (number) - 胎儿体重（克）
- `gestationalWeek` (number) - 孕周

返回值：
```javascript
{
  percentile: number,              // 百分位数 (5, 25, 50, 90, 95)
  classification: string,          // 分类描述
  reference: {
    p10: number,                   // 第10百分位体重
    p50: number,                   // 第50百分位体重（中位数）
    p90: number,                   // 第90百分位体重
    p95: number                    // 第95百分位体重
  },
  deviation: number                // 与中位数的偏差（克）
}
```

#### `getFetalWeightReference(gestationalWeek)`
**获取指定孕周的参考体重范围**

参数：
- `gestationalWeek` (number) - 孕周 (16-42)

返回值：
```javascript
{
  p10: number,    // 第10百分位
  p50: number,    // 第50百分位（中位数）
  p90: number,    // 第90百分位
  p95: number     // 第95百分位
}
```

## 重要医学提示

### 使用限制
1. **估算性质** - 体重计算基于Hadlock公式，是估算值而非精确测量
2. **误差范围** - ±10-15%属正常范围，不作为医学诊断依据
3. **医学咨询** - 任何异常情况应立即咨询产科医生
4. **个体差异** - 不同胎儿体重存在正常生理差异

### 正常参考值
- **胎心率** - 120-160 bpm，平均 140-150 bpm
- **胎动** - 孕20周后开始明显感觉
- **羊膜液指数** - 8-18 cm 属正常范围

### 常见异常信号
- 胎儿体重明显偏小（<P10）- 可能胎儿发育迟缓
- 胎儿体重明显偏大（>P95）- 可能存在巨大儿风险
- 胎心率异常 - 需立即就医

## 开发者注意事项

### 数据持久化
- 胎儿记录存储在App.js的baby对象的`fetalRecords`数组中
- 记录结构包含所有测量数据、计算结果和分类信息
- 目前无本地存储机制，应用重启后数据丢失（建议后期集成LocalStorage)

### 孕周的确定
- 应使用医学上的孕周计算方式（从末次月经第一天开始算起）
- 用户输入的孕周应基于医学检查确定的孕周

## 常见问题

**Q: 为什么计算结果和医生说的不一样？**
A: 可能原因：
1. 测量数据输入有误（请核对单位，应为毫米）
2. 孕周计算不同（应使用医学孕周）
3. 不同医院可能使用不同超声仪器或参考标准

**Q: 双顶径是必须的吗？**
A: 不是必须的。系统支持两种公式：
- 仅用HC、AC、FL（Hadlock III）
- 加上BPD获得更高精度（Hadlock I）

**Q: 可以用来判断胎儿是否异常吗？**
A: 不能。体重估算只是参考，医学诊断需由专业医生基于多项指标综合判断。

**Q: 数据会保存吗？**
A: 目前数据仅存储在应用内存中，重启应用后丢失。建议在重要就医前截屏保存。
