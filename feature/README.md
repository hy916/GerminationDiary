# 宝宝成长记录APP详细需求文档

# 一、项目概述

## 1\.1 项目背景

新手父母在宝宝出生后，需记录大量基础信息、喂养细节、日常状态及生长发育情况，当前多通过纸质笔记、备忘录等方式记录，存在信息零散、查找不便、统计困难、无法直观追踪成长趋势等问题。本APP旨在整合宝宝出生至成长各阶段的核心记录需求，提供便捷、全面、直观的记录工具，帮助父母系统化留存宝宝成长痕迹，同时为宝宝体检、就医提供精准的历史数据支撑，减轻育儿记录负担。

## 1\.2 项目目标

- 核心目标：打造一款专注于0\-3岁宝宝的成长记录工具，覆盖出生档案、喂养、日常状态、身体情况、生长发育全场景，实现记录便捷化、数据系统化、查看直观化。

- 用户目标：满足新手父母、祖辈等育儿者的记录需求，操作简单、界面简洁，无需复杂学习即可上手，同时支持数据备份、导出，确保信息不丢失。

- 产品目标：打造差异化成长记录工具，突出“全面性\+便捷性\+实用性”，解决传统记录方式的痛点，成为育儿家庭必备的辅助工具。

## 1\.3 适用人群

- 核心用户：0\-3岁宝宝的父母（新手父母为主，25\-35岁，对育儿细节关注度高，有记录习惯）。

- 次要用户：宝宝的祖辈（爷爷奶奶、外公外婆，协助照顾宝宝，需记录日常喂养、作息等细节）。

- 潜在用户：备孕家庭、孕期家庭（提前了解育儿记录需求，为宝宝出生后做准备）。

# 二、核心功能需求（按用户场景分类）

## 2\.1 基础模块：宝宝信息管理

### 2\.1\.1 宝宝档案创建与编辑

- 支持创建多个宝宝档案（适配多子女家庭），每个档案独立管理，可设置宝宝昵称、性别、出生日期，上传宝宝头像。

- 档案信息可随时编辑、修改，支持删除宝宝档案（需二次确认，防止误操作）。

- 切换宝宝档案便捷，首页可快速切换不同宝宝的记录内容。

### 2\.1\.2 基础出生档案记录（必记项，强制引导录入）

模块说明：宝宝出生后，引导用户优先录入基础出生信息，形成完整的出生档案，后续可随时补充、修改，支持上传相关凭证照片。

- 出生信息：
        

    - 必填项：出生日期（精确到日）、出生时间（精确到小时分钟）、孕周（精确到周\+天，如39周\+2天）、出生体重（单位：g/kg，支持手动输入或选择）、身长（单位：cm）、头围（单位：cm）、出生方式（单选：顺产/剖腹产/其他，其他可手动补充）、出生地（手动输入，支持选择地区）。

    - 可选项：血型（单选：A/B/O/AB/未知）、Apgar评分（0\-10分，单选\+手动备注，如“8分，无异常”）。

- 证件\&amp;体检信息：


    - 疫苗接种：支持按时间顺序记录，可添加“疫苗名称、接种时间、接种地点、接种人员、备注（如是否有不良反应）”，支持设置疫苗接种提醒（关联系统日历）。

    - 重点疫苗记录：单独标注卡介苗、乙肝第一针的接种时间，支持快速录入，可上传接种凭证照片。

    - 足跟血采集：采集时间、采集结果（正常/异常，异常可备注具体情况）、复查时间（如有）。

    - 听力筛查：筛查时间、筛查结果（通过/未通过/复查）、复查时间及结果（如有），支持上传筛查报告照片。

    - 儿保记录：支持按时间记录每次儿保的体重、身长、头围，自动计算生长差值，可添加儿保医生建议、儿保地点，上传儿保报告照片。

    - 黄疸记录：可按天数记录黄疸数值（单位：mg/dl），标注测量时间、测量方式（医院测量/家用仪器测量），支持添加备注（如“生理性黄疸，无需特殊处理”）。

    - 出院小结：支持手动录入关键内容（如出院诊断、注意事项、随访时间），或上传出院小结照片（支持OCR识别提取关键信息，减少手动录入）。

- 凭证管理：所有与出生、体检相关的照片（疫苗凭证、筛查报告、出院小结等），可统一在“凭证相册”查看、管理，支持分类归档。

## 2\.2 核心模块：日常喂养记录（高频使用）

### 2\.2\.1 母乳/奶粉喂养记录

- 快速记录入口：首页设置“喂奶记录”快捷按钮，点击即可快速录入，减少操作步骤。

- 基础信息：喂奶开始时间（默认当前时间，可修改）、结束时间（支持手动输入或计时结束自动填充），自动计算喂奶时长。

- 母乳喂养：
        

    - 喂养侧选择（单选：左侧/右侧/双侧），单侧喂养时长（如左侧15分钟、右侧10分钟）。

    - 吃饱状态（单选：吃饱/未吃饱/不确定），可添加备注（如“宝宝吸吮无力，未吃饱”）。

    - 支持记录溢奶/吐奶情况（是否溢奶、溢奶量、溢奶时间）。

- 奶粉喂养：
        

    - 奶粉品牌（支持搜索、选择，可添加常用品牌，自动记忆）、段位（单选：1段/2段/3段等，根据宝宝月龄推荐）。

    - 冲泡毫升数、实际喝入毫升数（支持手动输入，可设置快捷数值，如30ml、60ml、90ml）。

    - 可添加备注（如“奶粉冲调比例1:30，宝宝无过敏”）。

- 通用功能：
        

    - 喂养间隔：自动计算本次与上一次喂养的间隔时间，显示在记录详情中。

    - 夜奶标记：可标记本次喂养为“夜奶”，方便后续统计夜奶次数。

    - 批量编辑/删除：支持选中多条喂养记录，批量删除或修改（如统一修改奶粉品牌）。

    - 统计功能：自动统计每日/每周/每月的喂养次数、总喂养时长（母乳）、总奶量（奶粉）、夜奶次数，以图表（柱状图、折线图）形式展示。

### 2\.2\.2 辅食记录（适配6个月\+宝宝，可手动开启该模块）

- 基础设置：可设置辅食开始日期（默认宝宝6个月，可修改），记录第一口食物（名称、性状、日期）。

- 日常辅食记录：
        

    - 辅食信息：辅食种类（可多选，如“米粉、西兰花、高铁肉泥”）、食用量（如“10g、小半碗”，支持手动输入或选择快捷选项）。

    - 过敏监测：记录是否出现过敏反应（单选：无过敏/轻微过敏/严重过敏），过敏症状（如“红疹、呕吐、腹泻”，可多选\+手动备注），过敏处理方式（如“停止食用该辅食、就医”）。

    - 进食情况：可添加备注（如“宝宝爱吃，全部吃完”“抗拒进食，只吃了少量”）。

- 喝水记录：单独记录喝水时间、喝水量（单位：ml），支持快捷输入（如10ml、20ml），统计每日饮水量。

- 辅食档案：自动留存所有辅食种类，标记“已添加”“未添加”“过敏”，方便父母查看宝宝辅食添加情况，避免重复添加过敏食物。

## 2\.3 核心模块：吃喝拉撒日常记录

### 2\.3\.1 排便记录

- 快速记录：首页设置“排便记录”快捷按钮，支持一键标记排便时间（默认当前时间，可修改）。

- 核心信息：
        

    - 排便次数：单次记录1次，每日自动统计总次数。

    - 颜色：单选（金黄、浅黄、绿色、褐色、黑色、其他，其他可手动补充）。

    - 性状：单选（稀便、软便、硬便、糊状、水样便、成型便）。

    - 异常情况：可勾选（奶瓣、粘液、血丝、泡沫、异味），可添加备注（如“有少量奶瓣，无其他异常”）。

- 趋势查看：可查看每日/每周排便次数、性状变化，方便发现异常（如腹泻、便秘）。

### 2\.3\.2 小便记录

- 记录方式：支持两种记录模式——手动记录（每次尿不湿湿了手动标记）、批量记录（如“今日尿不湿湿了6次”，一次性录入）。

- 核心信息：小便次数、尿量（单选：少量、中量、大量），可添加备注（如“尿量偏少，需多喂水”）。

- 统计功能：自动统计每日小便次数，直观展示宝宝水分摄入是否充足。

### 2\.3\.3 睡眠记录

- 两种记录模式：
        

    - 计时模式：点击“开始睡眠”，宝宝醒来后点击“结束睡眠”，自动计算睡眠时长，标记睡眠类型（白天小睡/夜间睡眠）。

    - 手动模式：手动输入入睡时间、醒来时间，选择睡眠类型，自动计算睡眠时长。

- 核心信息：睡眠类型（白天小睡/夜间睡眠）、入睡时间、醒来时间、睡眠时长、夜醒次数（仅夜间睡眠可记录）、睡眠质量（单选：良好/一般/较差）。

- 统计功能：自动统计每日总睡眠时长、白天小睡次数及总时长、夜间睡眠时长，以图表形式展示睡眠趋势，帮助父母调整宝宝作息。

- 作息规律：可根据长期睡眠记录，生成宝宝的作息建议（如“建议每晚20:30前入睡，保证10小时夜间睡眠”）。

## 2\.4 核心模块：身体\&amp;状态记录

- 体温记录：手动输入体温（单位：℃/℉，可切换），记录测量时间、测量部位（腋下/额头/耳温），可添加备注（如“体温37\.5℃，轻微低烧，物理降温”），支持设置体温异常提醒（如体温≥37\.5℃提醒）。

- 健康状态：可勾选宝宝当日状态（打喷嚏、咳嗽、鼻塞、溢奶、吐奶），每种状态可添加备注（如“咳嗽，无痰，精神状态良好”）。

- 皮肤问题：记录湿疹、红屁屁、痱子等皮肤问题的出现时间、部位（单选：面部、颈部、臀部、四肢等）、症状描述（如“臀部发红，有少量红疹”）、处理方式（如“涂抹护臀膏，勤换尿不湿”）、恢复时间。

- 日常护理：记录洗澡时间、抚触时间、排气操次数及时长、晒太阳时长（单位：分钟），可添加备注（如“洗澡后做抚触，宝宝配合良好”）。

- 哭闹记录：记录哭闹时间、哭闹时长、哭闹原因（单选：饥饿、尿布湿、身体不适、困倦、无聊等，可手动补充）、安抚方式（如“喂奶、抱哄、听儿歌”）、安抚效果（单选：有效/无效/一般）。

## 2\.5 核心模块：生长发育记录

- 定期记录：支持按每周/每月记录宝宝的体重、身长、头围，可设置记录提醒（如“每月5日提醒记录生长数据”）。

- 生长曲线：自动生成体重、身长、头围的生长曲线，对照中国0\-3岁宝宝生长发育标准曲线，直观展示宝宝的生长情况（如“体重处于正常范围、身长偏上”），异常情况标注提醒（如“体重增长缓慢，建议咨询医生”）。

- 发育节点记录：
        

    - 大动作：记录宝宝抬头、翻身、坐、爬、站、走等大动作的首次出现时间，可添加照片/视频（如“宝宝6个月零5天首次独立坐起”）。

    - 精细动作：记录宝宝抓握、换手、捏取、翻书等精细动作的发育情况，标注首次出现时间。

    - 其他发育：可手动添加语言发育（如“会叫妈妈、爸爸”）、认知发育（如“能识别熟悉的人”）等情况。

- 发育评估：根据宝宝月龄和发育节点，给出简单的发育评估建议（如“宝宝7个月会翻身，符合正常发育节奏”），异常情况提醒家长及时就医。

## 2\.6 辅助模块：数据管理与备份

- 数据备份：支持本地备份（备份至手机内存）、云端备份（绑定手机号/微信/QQ，自动同步数据），防止数据丢失，支持手动触发备份。

- 数据导出：支持将宝宝的所有记录（出生档案、喂养、生长发育等）导出为Excel/PDF格式，方便打印、分享给医生（如儿保、就医时提供历史数据）。

- 数据删除：支持单个记录删除、批量删除，支持清空某一模块的所有记录（需二次确认），支持删除宝宝档案（删除后该宝宝所有数据一并删除，需二次确认）。

- 数据同步：多设备登录同一账号，数据自动同步（如手机、平板同时登录，记录内容实时同步）。

## 2\.7 辅助模块：提醒功能

- 自定义提醒：支持设置疫苗接种、儿保检查、生长记录、喂奶、辅食、洗澡等提醒，可设置提醒时间、频率（单次/每日/每周/每月）、提醒铃声。

- 智能提醒：根据宝宝月龄和历史记录，智能推送提醒（如“宝宝该接种乙肝第二针了”“宝宝6个月了，可开始添加辅食”“今日未记录宝宝排便，是否补充记录”）。

- 提醒管理：可查看所有提醒，支持开启/关闭提醒、编辑提醒内容、删除提醒。

## 2\.8 辅助模块：个人中心

- 账号管理：支持手机号、微信、QQ注册登录，支持修改密码、绑定/解绑账号，支持退出登录。

- 宝宝管理：可查看所有创建的宝宝档案，支持添加、编辑、删除宝宝档案，快速切换宝宝。

- 设置功能：支持修改APP主题（浅色/深色）、字体大小、提醒铃声，开启/关闭云端同步、自动备份，查看APP版本、更新APP、反馈问题。

- 帮助中心：提供常见问题解答（如“如何备份数据”“如何导出记录”）、使用教程（图文/短视频），支持联系客服（在线咨询、电话咨询）。

# 三、交互需求

## 3\.1 整体交互原则

- 简洁易用：界面布局清晰，核心功能（喂奶、排便、睡眠记录）放在首页，操作步骤不超过3步，适合育儿时快速操作。

- 反馈及时：操作后给出明确反馈（如“记录成功”“备份完成”），错误操作给出提示（如“请填写必填项”“备份失败，请检查网络”）。

- 一致性：相同类型的操作（如“添加”“编辑”“删除”）按钮样式、位置保持一致，降低用户学习成本。

- 便捷性：常用功能支持快捷操作（如首页快捷记录按钮、常用数值快捷选择），支持手势操作（如左右滑动切换宝宝档案、下拉刷新数据）。

## 3\.2 核心页面交互

- 首页：
        

    - 顶部显示当前宝宝昵称、月龄，支持点击切换宝宝。

    - 中间区域展示核心快捷记录按钮（喂奶、排便、睡眠、体温），按钮大小适中，便于快速点击。

    - 下方展示当日记录汇总（如“今日喂奶4次、排便3次、睡眠12小时”），点击可进入详细记录页面。

    - 支持下拉刷新，更新当日记录数据。

- 记录详情页：
       

    - 所有记录按时间倒序排列，最新记录显示在顶部。

    - 每条记录支持点击查看详情、编辑、删除，长按可批量选择删除。

    - 支持按模块筛选记录（如仅查看喂养记录、仅查看睡眠记录），支持按时间筛选（今日/昨日/本周/本月/自定义时间）。

- 生长曲线页：
        

    - 默认展示体重、身长、头围三条曲线，支持单独查看某一条曲线。

    - 点击曲线上的节点，可查看该节点的具体数据（时间、数值）。

    - 支持切换“每周/每月”数据视图，支持对比标准曲线（可开启/关闭标准曲线）。

- 提醒页面：


    - 所有提醒按时间顺序排列，未执行的提醒标注“未完成”，已执行的标注“已完成”。

    - 点击提醒可查看详情、编辑、删除，未完成的提醒可点击“标记为已完成”。

# 四、非功能需求

## 4\.1 性能需求

- 响应速度：点击按钮、切换页面、加载数据的响应时间≤1秒，记录提交、数据备份≤2秒，无明显卡顿。

- 稳定性：APP运行稳定，无闪退、崩溃现象，连续使用24小时无异常；数据录入、备份、导出无丢失、错乱。

- 兼容性：支持iOS 12\.0及以上版本、Android 8\.0及以上版本，适配不同尺寸的手机、平板屏幕（如全面屏、折叠屏）。

## 4\.2 安全需求

- 数据安全：用户数据（宝宝信息、记录内容）加密存储，云端备份数据加密传输，防止数据泄露、篡改。

- 账号安全：支持密码登录、验证码登录，连续输错5次密码锁定账号（1小时后解锁）；支持账号绑定，防止账号被盗。
